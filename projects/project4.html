Threat Intelligence Dashboard

Collects malicious URL data from threat feeds including Abuse.ch, stores entries in a structured database, and visualises threat trends.

Python Flask APScheduler MySQL
Overview

The system updates every minute via a scheduled job and is designed to support actionable threat response — including automatic detection and blocking through firewall integration.

Key Features
  • 60-second auto-refresh from threat feeds
  • Firewall integration for automatic blocking
  • Threat visualisation dashboard
  • Database persistence for historical analysis
